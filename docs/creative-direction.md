# CREATIVE DIRECTION CORRECTION — RESTORE VISUAL PERSONALITY

The previous redesign has become too minimal, visually flat, and generic.

The objective is NOT to make the portfolio as simple as possible. The objective is to achieve a balance between visual sophistication, creative expression, and professional credibility.

**New direction: Creative Developer × Editorial Design × Technical Precision.**

## What to preserve

- Dark visual foundation
- Strong editorial typography
- Clean content hierarchy
- Minimal unnecessary decorations
- Professional presentation
- Existing content, links, and functionality

## What needs improvement

### 1. Make the hero visually memorable

The current hero has a large headline on the left and excessive unused space on the right.

Rework the composition into an intentional asymmetric layout.

Introduce ONE distinctive hero visual that represents frontend engineering, creativity, or technical craftsmanship.

Potential approaches:
- An interactive geometric composition
- A carefully designed technical visualization
- A subtle animated grid or generative pattern
- An abstract 3D-inspired CSS composition
- An interactive typography experiment

Choose the approach that best fits the existing aesthetic and can be implemented efficiently.

Do not introduce random glowing spheres, generic floating blobs, or unrelated illustrations.

The visual must look intentionally art-directed and should enhance the headline rather than compete with it.

### 2. Introduce a recognizable accent color

The current black-and-white composition lacks visual identity.

Select one distinctive accent color and establish it as part of the design system.

Use the accent selectively for:
- Primary call to action
- Interactive states
- Important visual details
- Selected project highlights
- Small technical elements

Avoid applying it everywhere.

Maintain strong contrast and a sophisticated neutral foundation.

### 3. Improve the typography system

Preserve the editorial character of the headline, but introduce contrast between expressive display typography and precise technical typography.

Create a stronger relationship between:
- Large display headlines
- Clean sans-serif body text
- Small monospace technical labels
- Section numbering and metadata

The result should feel like a creative developer portfolio, not a generic editorial magazine.

### 4. Add meaningful visual detail

Introduce carefully controlled personality through:
- Technical grid structures
- Section indices
- Small interactive elements
- Asymmetric composition
- Distinctive dividers
- Creative project image framing
- Subtle visual layering
- Carefully composed negative space

Do not place everything inside cards.

Not every section should have the same structure.

### 5. Make projects visually compelling

The project showcase should become a central part of the visual experience.

Instead of uniform project cards, use:
- Larger featured projects
- Real project screenshots
- Varied editorial compositions
- Strong project typography
- Clear technology metadata
- Purposeful hover interactions

Visitors should be able to recognize the quality and diversity of the work immediately.

### 6. Introduce purposeful motion

The website should feel alive without becoming distracting.

Consider:
- Subtle hero visual interaction
- Polished headline entrance
- Magnetic-style CTA feedback with restrained movement
- Smooth project image reveals
- Responsive hover transitions
- Minimal section transitions

Use Framer Motion or CSS where appropriate.

Avoid excessive parallax, constant movement, unnecessary scroll animations, and effects that harm accessibility.

Support reduced-motion preferences.

### 7. Strengthen CTA hierarchy

Make "View projects" the primary action.

Keep "Download CV" as a secondary action and "Get in touch" as a clearly accessible alternative.

Use clear size, contrast, and interaction differences.

### 8. Keep the design cohesive

Do not add isolated effects to solve the blandness.

Establish a recognizable visual language and reuse it consistently throughout the website.

Every creative element should feel like part of the same design system.

## Critical constraints

- Do not revert to generic SaaS-style visuals.
- Do not introduce purple gradients or excessive glassmorphism.
- Do not sacrifice readability for experimentation.
- Do not turn the portfolio into a flashy animation demo.
- Do not fill every empty space just because it exists.
- Do not replace the current personality with another generic template.
- Preserve the existing React, TypeScript, Tailwind, and Framer Motion stack.
- Maintain responsiveness, accessibility, performance, and GitHub Pages compatibility.

## Success criteria

The redesigned website should feel:

- 70% polished and professional
- 30% expressive and experimental

These percentages are creative guidance, not literal design measurements.

The portfolio should have at least one memorable visual signature without becoming visually overwhelming.

The desired impression is:

**"This developer understands both engineering and design."**

## Implementation

Inspect the existing frontend and implement the changes directly.

Start with the hero, navigation, and global design system. Then carry the visual direction into projects and supporting sections.

Evaluate the result at desktop and mobile viewport sizes.

Do not solve the problem by simply adding more decorative components. Improve the composition, visual hierarchy, and interaction design first.

The final result should be distinctive, refined, technically credible, and clearly personal.
